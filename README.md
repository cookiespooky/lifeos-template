# Шаблон хранилища Obsidian для работы с ИИ-агентом

Готовое хранилище Obsidian, которое Claude Code или Codex понимает с первого разговора: папки для входящих, мыслей,
заметок дня, задач, людей и проектов, правила для агента (`AGENTS.md`) и три инструкции — разобрать входящие,
записать про человека, завести задачу. Кода и серверов нет, модель — ваша. Бесплатно.

## Как скачать

Кнопка **Code → Download ZIP** на этой странице, или `git clone` этого репозитория. Распакуйте туда, где будут жить
заметки, и откройте **«Начните отсюда.md»** — там установка за 10 минут.
