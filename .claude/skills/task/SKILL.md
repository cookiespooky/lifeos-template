# Задача

Задача — одна строка в `tasks/backlog.md`, в формате плагина Obsidian Tasks. Статус — только в строке.

```
- [ ] что сделать [[personalities/Имя]] #тег 📅 2026-12-01
```

| знак | что | когда ставить |
|---|---|---|
| `📅 дата` | срок | только настоящий: обещали, назначили, иначе будет поздно |
| `⏳ дата` | день, когда делать | владелец сам выбрал день |
| `🛫 дата` | раньше не начать | задача не имеет смысла до этой даты |
| `⏫` `🔼` `🔽` | высокий, средний, низкий приоритет | если владелец его назвал |
| `#тег` | раздел | тот, что у раздела в бэклоге |

## Завести

1. **Сначала найди похожую** — по словам и по человеку. Нашлась — дополни её, а не заводи вторую.
2. Текст — что сделать, глаголом, так, чтобы через месяц было понятно без контекста. Человек или проект — ссылкой.
3. Строка — в раздел бэклога по теме; раздела нет — в «Входящие». Новые разделы заводит владелец или ты после его «да».
4. Даты — `ГГГГ-ММ-ДД`; «в пятницу» переведи в дату и назови её владельцу.

## Закрыть, отменить, перенести

- Сделано: `- [x] … ✅ ГГГГ-ММ-ДД`. Отменено: `- [-] …` и коротко почему, в конце строки.
- Перенос срока — поменяй дату в строке; если срок сдвигается не первый раз — скажи владельцу.
- Нашлось несколько подходящих строк — покажи их и спроси, какую.

## «Что на сегодня», «что просрочено»

Собери из бэклога: открытые с `⏳` или `📅` на сегодня; просроченные (`📅` раньше сегодня); с `⏫` без даты. Покажи
коротко, по разделам, просроченные первыми. Заметка дня `journal/` показывает то же запросами Tasks.
